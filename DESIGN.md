# Task workspace

The task workspace follows the user's selected Codex/Claude composition. It is an operating
tool for long coding sessions. Familiar controls, restrained density, and readable content
matter more than ornamental presentation.

- A quiet neutral task rail, white conversation surface, and a separate plan inspector.
- Segoe UI/system sans for interface and prose; monospace only for code and paths.
- Blue remains the AgentVisor action accent. Green means verified, amber needs attention.
- Compact header with task identity, state, and pause/resume. Secondary controls stay secondary.
- Conversation occupies the viewport; its composer remains reachable without scrolling.
- User messages, agent text, and operational details have distinct hierarchy. Tools and
  reasoning are collapsed, original content is preserved, and older messages are reachable.
- Reading position and focused input remain stable during background refresh.
- On small screens the task rail becomes a dismissible drawer and the inspector a separate
  view. Main controls stay keyboard accessible with visible focus and meaningful labels.
- Charts, resource meters, task documents, and limits are available under task details.
- No generated imagery, decorative gradients, or dashboard cards in the conversation.

The durable plan and user requirement protocol continue to govern every UI operation.
