# Проверки AgentVisor

Команды выполняются из корня репозитория. Для автоматических тестов модель
не нужна: процессы агента и ответы модельных серверов имитируются.

## Python и JavaScript

Используйте Python из виртуального окружения проекта и установленный Node.js:

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
node tests/test_frontend_i18n.mjs
```

Python-тесты проверяют цикл задач, остановку дерева процессов, паузу и продолжение,
таймауты, пределы повторов, отсутствие прогресса, смену цели, устаревший DONE,
независимую проверку результата, защиту API и адаптеры моделей.
Проверки локализации охватывают язык API, события, подстановки и сохранность
произвольного пользовательского текста.

Тесты запуска проверяют файловую блокировку между процессами, понятное сообщение
при занятом каталоге и повторное открытие прежнего экземпляра после обновления
исходников. Отдельный HTTP-прогон меняет 127.0.0.1 → 0.0.0.0 → 127.0.0.1 через
API с реальными перезапусками и проверяет сохранность задачи и кода доступа.
Проверки сети охватывают вход/выход, Origin, CSRF, поддельный X-Forwarded-For,
неверный Host и запрет перезапуска при активной задаче или операции с моделью.

## Linux в Docker

```sh
docker build -t agentvisor:local .
docker run --rm agentvisor:local python -m tests.smoke_container
docker run --rm agentvisor:local sh -c "pip install --user -r requirements-dev.txt && python -m pytest -q -p no:cacheprovider && node tests/test_frontend_i18n.mjs"
```

HTTP-проверка запускает приложение и демонстрационного агента, проверяет создание
задачи, четыре итерации, чек-лист, журнал и защиту API. Контейнер удаляется после
выполнения; модель не загружается.

## Реальная модель

Для отдельного интеграционного прогона нужны установленный OpenCode, работающий
LM Studio и скачанная модель с поддержкой инструментов:

```sh
python -m tests.smoke_model --model <идентификатор-модели>
```

Для Ollama добавьте `--runtime ollama --url http://127.0.0.1:11434`.
Тест создаёт отдельный каталог в `.agentvisor-data/`, запускает OpenCode с
разрешёнными инструментами и проверяет точное содержимое созданного файла.
В `result.json` сохраняются результат и события. Такой прогон использует
ресурсы модельного сервера и может загрузить или перезагрузить модель.

## Проверка интерфейса

Откройте обзор, задачи, модели, историю и настройки. Проверьте переключение RU/EN,
сохранение введённых полей и выбранного языка после перезагрузки, переход из
события в журнал, клавиатурную навигацию и узкий экран.
Запустите демонстрацию: проверьте обновление плана, паузу, продолжение и итог.

В отдельном тестовом каталоге данных проверьте **Настройки → Сетевой доступ**:
сохранение выбора при смене языка, скрытие/показ кода, сообщение об ожидающем
перезапуске и повторное подключение после применения адреса. С другого устройства
должен появиться вход по коду; ошибочный код не открывает панель. Возврат к
127.0.0.1 отключает сетевое подключение. Для Docker проверяйте публикацию порта
и AGENTVISOR_ALLOWED_HOSTS по инструкции в README.

Короткие автоматические и интеграционные проверки не подтверждают устойчивость
ночного запуска, восстановление после отключения питания или работу всех GPU.
Для длительной проверки используйте отдельную копию проекта, ограничьте время
задачи и задайте независимую команду проверки результата.
